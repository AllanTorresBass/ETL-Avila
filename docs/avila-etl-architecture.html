ETL architecture

Person-centered schema, page-level Blob uploads, and the Next.js reader. This page mirrors docs/avila-etl-architecture.md.

1. Purpose and scope

  • Client = person (titular / beneficiary).
  • Account = billed insurer or company.
  • First load = invoice universe from invoices.csv.
  • Miranda scanner lots without a FACT number stay out of this load.

4. Split and Blob

One page = one document = one Blob object.

avila/invoices/{invoice}/{source_sha}/{page}-{type}.png

The linked store currently requires public access. The reader still uses /api/blob/[id] so private signed URLs can replace the redirect later.

5. How to run

psql "$DATABASE_URL_UNPOOLED" -f sql/001_schema.sql -f sql/002_seed_accounts.sql
cd scripts && npm install
python3 scripts/upload_documents_to_blob.py --paths-file output/invoices/pilot-paths.txt
cd web && npm install && npm run dev

Env names only: DATABASE_URL, DATABASE_URL_UNPOOLED, BLOB_READ_WRITE_TOKEN.
